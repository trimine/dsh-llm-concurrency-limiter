# Changelog / 更新日志

## 1.0.0 — First public release / 首个公开版本

- Provider, model, global and session concurrency controls / 提供商、模型、全局与会话并发控制。
- Sidebar settings and session quick control / 侧边栏配置与会话快捷设置。
- Provider discovery and custom rules / 提供商发现及自定义规则。
- Persistent shared configuration via DSH configEditor / 通过 DSH 配置编辑器保存统一配置。
- Queue cancellation, timeouts, disposal and limit accounting fixes / 排队取消、超时、卸载清理与计数修复。
- Local-only configuration endpoints with request validation / 本机配置接口及请求校验。
- 14 regression tests and bilingual documentation / 14 项回归测试与中英文说明。

Development-only 1.1.x numbering is reset to 1.0.0 for the first public release; this is not a feature rollback.
开发期间使用的 1.1.x 版本号重置为 1.0.0，用作首个公开发布版本，不代表功能回退。
